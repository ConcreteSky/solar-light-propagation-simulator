# Visual asset sources

All current visual assets are original project SVGs created during setup and may be used with the project without an external license dependency:

- `earth-simple.svg`: flat ocean, land, and cloud bands.
- `jupiter-bands.svg`: flat bands and a simplified oval storm.
- `moon-craters.svg`: reusable muted crater pattern for rocky bodies.
- `saturn-rings.svg`: reusable flat ring band texture.

Other bodies use the color/material catalog in `frontend/src/data/materials.js`. Textures and colors are illustrative only and are never inputs to scientific calculations.
