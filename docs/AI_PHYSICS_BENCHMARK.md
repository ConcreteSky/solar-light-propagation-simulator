# AI–Physics Reliability and Efficiency Benchmark

## Scope

This benchmark compares the deterministic light-interaction model, the five-model ML ensemble, and a hybrid system that automatically defers to physics. It measures the current implementation rather than an idealized surrogate.

## Environment and reproducibility

The recorded environment, versions, seeds, and settings are saved in `research/results/reliability_efficiency/environment.json`. The experiment uses Python 3.14, seeds 741–745, physics version 1.0.0, model version 1.0.0, reliability version 1.0.0, and dataset generator version 1.0.0.

Rebuild the ensemble and thresholds from `backend/`:

```powershell
.\.venv\Scripts\python.exe -m training.build_reliability_artifact
```

Re-run the complete benchmark and regenerate all CSV/PNG outputs:

```powershell
.\.venv\Scripts\python.exe -m training.run_reliability_benchmark
```

## Samples

The evaluation contains 4,000 cases:

- 1,000 untouched test rows from the versioned synthetic dataset;
- 1,000 near-boundary cases at 50–70 AU and 5–10 MPa;
- 1,000 moderate-shift cases at 70–100 AU and 10–20 MPa;
- 1,000 severe-shift cases at 100–150 AU and 20–50 MPa.

The source data spans ordinary, thin, dense, mixed-gas, irradiance, distance, airless, boundary, and shifted regimes. Shifted labels are generated by the same deterministic physics function.

## Timing method

Batch methods receive three warm-up calls and 12 measured calls. Physics, AI, and hybrid methods run in rotating order to reduce ordering and thermal bias. Single-input physics and ensemble inference receive a warm-up and 100 measurements. Model loading is measured separately over five loads. Runtime excludes artifact training.

The initial implementation of the benchmark produced an impossible hybrid speed advantage due to order-dependent warm-cache effects. Those results were discarded; the saved results use equal warm-up and interleaved timing.

## Main comparison

| System | Mean absolute error | Median batch ms/sample | AI usage | Fallback | Raw minor-violation rows |
| --- | ---: | ---: | ---: | ---: | ---: |
| Physics only | 0.000000 | 0.08684 | 0.0% | 100.0% | 0 |
| ML only | 0.012930 | 0.09822 | 100.0% | 0.0% | 3,998 |
| Hybrid q99 | 0.005421 | 0.12806 | 67.7% | 32.3% | 2,707 accepted rows |

Physics error is zero by construction, because it generated the labels. The q99 hybrid reduced ML-only mean absolute error by 58.1% and reduced errors above 0.02 from 28.30% to 9.95%, but it was 47.5% slower than physics-only and 30.4% slower than ML-only in the final batch measurement. Relative to physics, measured speedup ratios were `0.884×` for ML-only and `0.678×` for the hybrid; values below one are slowdowns.

Single-input medians were `0.0339 ms` for deterministic physics and `151.8572 ms` for the ensemble. Batch throughput was 11,516 samples/s for physics, 10,182 samples/s for AI, and 7,809 samples/s for the hybrid. Five-pipeline feature preprocessing alone measured `0.00767 ms/sample`. No inference speedup is claimed.

The compressed ensemble artifact is 5,619,774 bytes. Recorded `tracemalloc` peaks were 1,379,160 bytes for the physics batch and 2,200,389 bytes for the ensemble batch; these figures exclude some native-library allocations. Median artifact loading was 497.65 ms in the final run and is reported separately from steady-state inference.

## Threshold experiment

| Policy | AI usage | Fallback | Mean error | Error > 0.02 | Median ms/sample |
| --- | ---: | ---: | ---: | ---: | ---: |
| AI only | 100.0% | 0.0% | 0.012930 | 28.30% | 0.09822 |
| OOD q99 + uncertainty q99 | 67.7% | 32.3% | 0.005421 | 9.95% | 0.12806 |
| OOD q99 + uncertainty q95 | 61.4% | 38.7% | 0.004744 | 8.78% | 0.13389 |
| OOD q95 + uncertainty q95 | 31.0% | 69.0% | 0.000702 | 0.85% | 0.16157 |
| Physics only | 0.0% | 100.0% | 0.000000 | 0.00% | 0.08684 |

More conservative fallback improves accuracy but increases hybrid runtime. The q99 policy was selected to retain the largest tested AI usage while materially reducing error. This choice demonstrates the trade-off; it does not outperform physics on runtime.

## Reliability relationships

- Uncertainty vs error: Pearson `0.259`, Spearman `0.462`.
- OOD score vs error: Pearson `0.566`, Spearman `0.723`.

Quartile-bin mean error rose from `0.00512` in the lowest-uncertainty bin to `0.01606` in the highest, but the middle bins were not strictly monotonic. OOD bins were clearer and monotonic: `0.00091`, `0.00998`, `0.01588`, and `0.02495` from low to very high. OOD distance is therefore the stronger ranking signal. Neither detector is perfect. Saved failure cases include high-error/low-uncertainty predictions, overly conservative uncertainty flags, and safe predictions rejected by OOD.

## Interpretation

The reliability evidence supports a limited claim: combining OOD distance, ensemble disagreement, physical checks, and deterministic fallback reduces surrogate error under controlled shift. It does not support the stronger claim that this ensemble accelerates the current deterministic simulator. Synthetic-label agreement is not independent observational validation.
